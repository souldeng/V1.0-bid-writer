# 匿名示例项目

本示例仅用于演示本地工作流，所有名称、数字和描述均为虚构内容；请勿将其理解为真实客户、采购项目或政策承诺。

## 创建项目时填写

| 字段 | 示例值 |
| --- | --- |
| 项目名称 | 青屿市社区服务数据协同示例项目 |
| 申报主体 | 示例数字服务机构 |
| 级别 | 市级示例 |
| 地区 | 青屿市（虚构） |
| 预算 | 按实际演示需要填写，不附带参考金额 |
| 领域 | 公共服务数据协同 |
| 建设内容 | 建立材料归集、事项协同、进度看板和人工复核流程的演示方案。 |
| 优势 | 采用模块化服务、最小权限和人工校验，便于演示数据边界。 |

## 匿名体验步骤

1. 创建上述项目，不上传任何真实材料。
2. 在目录编辑器中创建“项目背景”“建设目标”“实施计划”三个章节，或使用默认目录。
3. 手工输入一小段虚构内容并保存，验证切换章节和刷新后的恢复效果。
4. 如需测试材料检索或模型生成，只上传自行编写的无个人信息 TXT/Markdown 文本，并使用自己的服务端密钥。
5. 导出 DOCX 后，确认其中没有密钥、个人信息或未经授权的材料再分享。

该示例刻意不提供真实招标文件、联系方式、预算、单位名称或效果数据。
