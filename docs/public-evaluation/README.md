# Public evaluation note

This repository does not publish raw RAG experiment inputs, prompts, outputs, ZIP archives, or reviewer records. Those artifacts can contain project context or identifiers even when filenames look generic.

## Reproducible method for a future public comparison

1. Build a fully fictional fixture with no personal data, customer material, real organization, or production credential.
2. Hold the model, prompt template, retrieval corpus, generation settings, and review rubric constant.
3. Compare retrieval disabled and enabled using the same fixture and record the complete procedure, failures, and reviewer criteria.
4. Publish only anonymized aggregate results that can be reproduced from the public fixture.

No public improvement percentage is claimed here. Existing internal experiment results have not been independently reproduced on a publishable fixture.
